## Exercise #004 — IP Address Analysis

### Challenge
Analyze the IP address 5.155.33.127 and extract accurate geolocation and network information.

### Tools Used
- Python (ip_lookup.py)
- ipinfo.io
- ip-api.com
- ipwho.is

### Solution
The IP belongs to Syrian Telecom / Tarassul ISP in Syria.

### Final Verified Results
- IP: 5.155.33.127
- Country: Syria (SY)
- ISP: Tarassul Internet Service Provider
- Organization: Syrian Telecommunication Private Closed Joint Stock Company
- ASN: AS29256
- Timezone: Asia/Damascus (+03:00)
- City: Damascus
- Coordinates: 33.5102, 36.2913

### Methodology
1. Queried three independent IP intelligence sources.
2. Compared geolocation results.
3. Identified inconsistent city data (Latakia vs Damascus).
4. Selected the result confirmed by two sources.
5. Documented ISP, ASN, and organizational data.

### Observations
- ip-api.com showed Latakia.
- ipinfo.io and ipwho.is both showed Damascus.
- Majority result: Damascus.
